# README

  - Built with Ruby on Rails 8 for personal expense and budget tracking.
  - Lets users set a monthly budget and record daily expenses.
  - Expenses are organized by categories like food, transport, shopping, health, entertainment, and other.
  - Includes dashboard views for overall, daily, monthly, and savings analysis.
  - Shows key insights such as total spent, remaining budget, savings rate, and top spending category.
  - Uses SQLite for storage and Chart.js for visual spending reports.
  - Designed as a simple single-budget tracker with clean CRUD-based expense management.
